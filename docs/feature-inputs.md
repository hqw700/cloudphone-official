# 高级输入：汉字输入、剪切板与按键映射 (Advanced Inputs)

在远程控制 Android 设备时，中文输入法打字受阻、剪切板无法双向同步以及端游按键不跟手是业界常见痛点。  
ScrcpyOverWebRTC 构建了由 **100% 汉字落屏输入法、静默双向剪切板以及可视化按键映射引擎** 组成的完整高级输入体系。

---

## ⌨️ 一、100% 拼音输入法汉字无感落屏

### 1. 技术痛点与突破
- **底层限制**：Android 原生 `InputManager` 和 scrcpy 的 `injectChar` 接口仅支持物理 ASCII 字符码注入，直接输入汉字会被系统底层直接抛弃，报 `Could not inject char` 错误。
- **创新解决方案**：
  1. 前端在控制视窗内构建了 **1px 全透明 textarea 会话管理机制**，在鼠标点击云手机画面时锁定物理焦点；
  2. 监听浏览器的 `compositionstart` / `compositionend` 拼音合成事件；
  3. 当用户在电脑上输入中文并敲击空格完成落词后，前端自动将汉字文本写入 Android 系统剪贴板，并瞬间向底层发送粘贴指令（Paste）；
  4. **效果**：实现无需在云手机内额外安装特殊输入法即可达到 **100% 汉字流畅落屏**。

### 2. 使用方法
在网页控制界面点击云手机内的任意输入框，直接在电脑物理键盘上敲击中文输入法（如搜狗拼音、微软拼音、微信输入法等），选词后即可瞬间上屏。

---

## 📋 二、静默双向剪切板同步

系统实现了电脑端与云手机端之间的双向静默剪切板同步机制：

### 1. 工作机制
- **焦点回弹同步**：当用户从电脑其他窗口切回云手机控制界面时，前端会自动检测本地剪贴板变化，并通过 WebRTC DataChannel 静默推送至云手机；
- **快速快捷键支持**：在画面上直接按下 `Ctrl + V`（Mac 下 `Cmd + V`），即可将电脑中的长文本或链接直接粘贴至云手机光标处；
- **防无限回环**：两端均维护最近同步文本的哈希值判重，杜绝产生跨端无限相互复制死循环。

## 🎮 三、可视化按键映射编辑器 (Keymapping)

系统内置了类似安卓模拟器的全功能可视化改键编辑器，支持将键盘按键映射到屏幕特定坐标与手势。

### 1. 核心按键类型支持

| 映射类型 | 作用机制 | 适用场景 |
| :--- | :--- | :--- |
| **Tap (普通点击)** | 绑定单个按键（如 `Space`）到固定屏幕坐标 (`X, Y`)，按下触发 Down，抬起触发 Up | 技能释放、跳跃、开火、确定按钮 |
| **Joystick (8轴移动轮盘)** | 绑定 `WASD` 4 个方向键至虚拟轮盘中心与半径，动态计算方向向量模拟平滑摇杆走位 | MOBA 游戏走位、FPS 跑图移动 |
| **Swipe (线性滑动手势)** | 绑定单个按键执行从起点到终点的线性平滑滑动，可自定义滑移动画时长 | 短视频上下翻页、滑动解锁 |
| **Command (物理系统键)** | 将物理按键（如 `Esc`）直接映射为 Android 系统的 `BACK`、`HOME` 或 `POWER` 物理按键 | 快捷退出、一键返回桌面 |

### 2. 编辑器使用步骤
1. 在直控界面右侧工具栏中点击 **“按键映射编辑器”** 图标。
2. 从顶部工具条将所需的按键类型（如 Tap 或 Joystick）拖拽到云手机屏幕上的对应位置。
3. 点击按键，在物理键盘上按下想要绑定的实体键位（如 `F`）。
4. 点击 **“保存配置”**。
5. 配置将自动持久化保存在浏览器本地 `localStorage`，支持导出与导入配置方案（JSON 格式）。
