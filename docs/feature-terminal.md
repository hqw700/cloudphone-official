# 远程终端：xterm.js 交互与批量宏指令 (Terminal & Commands)

ScrcpyOverWebRTC 为运维工程师与开发者提供了两种维度的终端能力：**基于 `xterm.js` 的真交互式多会话 Shell 终端**，以及面向批量运维的 **命令行分发终端与自定义快捷宏系统**。

---

## 💻 一、xterm.js 多会话真交互式 Shell 终端

传统 Web 终端常因无法处理交互式 ANSI 转义字符而导致执行 `top` 或 `vi` 时界面错乱或阻塞。

### 1. 核心技术特性
- **xterm.js 引擎集成**：嵌入业界标准的 `xterm.js` 渲染引擎，完整支持 ANSI 颜色代码、行缓冲区以及光标定位，可完美运行 `top`、`logcat`、`htop`、`vi` 等交互式程序；
- **多会话多 Tab 并行**：直控界面支持点击 `+` 新建多个独立的 Shell 会话，每个 Tab 拥有独立的指示灯标识与底层 UDS 管道；
- **免装 ADB 客户端**：通过 WebRTC DataChannel 直接与设备底层的 Agent Shell 守护进程通信。

### 2. 使用方法
在设备直控界面的底部面板中选择 **“Shell 终端 (ADB)”**，即可直接在黑色终端中敲击命令进行交互调试。

---

## ⚡ 二、批量命令分发与自定义快捷宏

针对同时给数十台设备执行批量运维、信息采集或故障排查的场景，系统提供了非交互式的批量命令分发中心。

### 1. 批量命令并发下发
- **目标设备灵活选择**：支持一键“全选/全不选”，并支持按已配置的 **设备标签 (Tags)** 一键点选关联的在线设备；
- **状态与输出汇总**：指令通过信令通道并发分发给所有目标 Agent 执行，执行结果实时汇总返回，大盘高亮呈现状态（⏳执行中、✅成功、❌失败），点击即可展开查看对应设备的完整 `stdout` / `stderr` 输出。

### 2. 预置与自定义快捷宏指令 (`shortcuts.json`)
- **常用预置指令**：
  - **当前页面**：执行 `dumpsys window | grep mCurrentFocus` 获取前台正在运行的应用 Activity；
  - **三方应用**：执行 `pm list packages -3` 查看已安装的用户应用；
  - **设备型号**：获取 `getprop ro.product.model`；
  - **触摸轨迹开关**：控制 `settings put system pointer_location 1/0`。
- **自定义宏指令与云端持久化**：
  - 在控制台右侧点击 **“⚙️ 自定义快捷指令”**，可自主添加、编辑或删除常用运维脚本；
  - 数据自动持久化在服务端的 `data/shortcuts.json` 中，按登录用户隔离存储，实现多端漫游热同步。
