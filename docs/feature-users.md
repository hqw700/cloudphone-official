# 多账号、租户权限与操作审计 (Multi-User & Audit Logs)

为了满足工作室多员工协同、企业客户分租以及设备权限隔离的商业化需求，ScrcpyOverWebRTC 内置了完备的 **多账号角色体系、设备权限物理隔离、一站式全景管理抽屉以及全流程管理员操作审计系统**。

---

## 👥 角色与权限体系

系统支持两大核心用户角色：

| 角色类型 | 标识 | 权限边界与能力 |
| :--- | :--- | :--- |
| **超级管理员** | `admin` | 拥有平台最高控制特权。可查看所有在线/离线设备、创建/编辑/删除用户、进行设备分配、查阅操作审计日志、配置全局系统参数与商业授权 |
| **普通用户** | `user` | 租户角色。**仅能看到并控制管理员显式指派给自己的设备**，未分配的设备对该用户完全不可见；不可访问管理面板与审计中心 |

> 🌟 **VIP 特权模式**：支持为特定普通用户开启 VIP 免计费特权，满足特定商业客户的差异化服务需求。

---

## ⚙️ 一站式全景管理抽屉 (`UserDetailDrawer`)

在管理后台（顶部进入「管理」），点击任意用户行的 **“⚙️ 配置”** 按钮即可呼出一站式全景管理抽屉，集中完成以下维护：

### 1. 基础信息与安全
- 修改用户名、备注信息与密码重置；
- 调整用户角色（`admin` / `user`）与状态开关。

### 2. 设备资产精准指派
- 在设备列表中通过搜索框模糊检索，勾选需要授权给该用户的设备；
- 支持一键全选/取消全选，未勾选的设备在普通用户登录时将被物理隔离。

### 3. 策略锁定与有效期管控
- **有效期设置**：支持快捷一键续期（`+7天` / `+30天` / `+1年` / `永久有效`），到期后用户将无法登录连接；
- **连接策略强制锁定**：
  - 强制最高视频码率（限制用户占用服务器带宽）；
  - 强制最大帧率与分辨率长边；
  - 强制开启/关闭音频传输。

### 4. 实时活动连接监控与一键强退 (Kick Device)
- 抽屉内可实时查看该用户当前正在连接占用的设备标签与时长；
- 管理员可随时点击 **“一键强退”**，服务端信令将即时切断该连接并释放设备。

## 📜 全流程管理员操作审计系统 (`admin_logs.json`)

系统在所有管理端接口中集成了自动化审计切面，确保所有管理行为均可追溯：

### 1. 审计捕获范围
自动捕获并记录以下敏感操作：
- 创建用户、删除用户、修改备注、重置密码；
- 设备指派与收回；
- 画质与音频策略变更；
- 云币资产变动与充值记录；
- 强退设备与踢人操作。

### 2. 审计日志特性与安全
- **持久化存储**：写入 `data/admin_logs.json`，采用 `tmp + rename` 原子安全写入（`0600` 权限），最多自动轮转保留最近 3000 条记录；
- **日志字段包含**：操作发生时间、操作管理员、目标受影响用户、操作动作类型、变更前后参数 Diff、操作人客户端真实 IP。
- **可视化检索**：在管理面板点击顶部 **“📜 操作审计”**，支持按目标用户名模糊搜索以及按动作类型精准筛选。
