# 多账号、设备租约与操作审计 (Multi-User, Lease & Audit)

为了满足云手机出租、工作室多员工协同以及设备权限隔离的商业化需求，ScrcpyOverWebRTC 内置了完备的 **多账号角色体系、设备租约（Lease）模型、细粒度功能策略锁定以及全流程管理员操作审计**。

---

## 👥 角色与权限体系

系统支持两大核心用户角色：

| 角色类型 | 标识 | 权限边界与能力 |
| :--- | :--- | :--- |
| **超级管理员** | `admin` | 拥有平台最高控制特权。可查看全部设备、管理用户与租约、创建分享/卡密、下发批量任务、查阅审计日志、配置全局系统参数与商业授权 |
| **普通用户（租户）** | `user` | **仅能看到并使用自己持有活跃租约的设备**，其余设备对其完全不可见；导航只保留「虚机 / 文件 / 退出」，不可访问任何管理页面 |

首次启动自动创建默认管理员 `admin / admin123`（登录后请尽快修改密码）。

---

## 📜 设备租约模型 (Lease)

出租场景的核心抽象：**一台设备同一时刻只允许一个活跃租约（独占）**。

- **双时长维度，互不影响**：
  - 账号级 `expires_at` 管**登录资格**（到期无法登录，零值 = 永久）；
  - 租约级 `expires_at` 管**单台设备的使用权**（到期自动回收，零值 = 永久）。
- **自动回收与踢断**：服务端每分钟巡检到期租约并自动回收，同时即时踢断该租户在该设备上的在线连接。
- **租客视角透明化**：
  - 设备卡片/列表行实时显示「我的剩余时长」（如 `剩余 6 天 3 小时`，≤1 天橙色警示，永久显示 `♾️ 永久`）；
  - 顶栏倒计时自动切换为「最近到期的租约」剩余时间；全部租约永久时回退显示账号有效期。
- **逃生门**：用户的 `assigned_devices = ["*"]` 时表示全设备可见（兼容旧分配模式），租约为空时不影响管理员使用。

管理员通过租约 API（`/api/admin/leases/*`）完成创建、续期、撤销与策略覆盖，全部操作留痕。

## 🔒 策略锁定与功能管控 (Policy)

管理员可按用户（或按单条租约覆盖）配置 **7 个功能禁止位 + 画质锁定值**，经 `/api/me` 下发后由前后端双端强制：

| 策略位 | 管控效果 |
| :--- | :--- |
| `forbid_bitrate` / `forbid_fps` / `forbid_resolution` / `forbid_audio` | 画质四项锁定：设置面板对应项置灰，服务端强制使用管理员配置值 |
| `forbid_file_push` | 屏蔽文件上传/推送入口（文件管理页上传、批量分发）；服务端同时拦截 `/upload` 与签名下载链接签发 |
| `forbid_terminal` | 屏蔽终端 Shell、ADB 调试、AI 助手（P2P shell 通道）与快捷键命令按钮（电源/HOME/自定义按键等）；服务端在信令层拦截 `command` 消息 |
| `forbid_share` | 禁止创建设备分享/卡密 |

> 批量任务（批量 Shell、批量安装/文件分发，`/api/tasks`）为管理员专属能力，普通用户界面不展示入口，服务端同步 403。

## 🖥️ 管理端五大页面

管理后台位于顶部「管理」入口，按职责拆分为五个页面：

| 页面 | 路径 | 职责 |
| :--- | :--- | :--- |
| **用户权限管理** | `/admin/users` | 创建/删除/改名用户、重置密码、账号有效期、策略锁定、一键强退在线会话 |
| **设备租约运营** | `/admin/devices` | 全量设备租约视图：发放租约、续期、撤销、租约级策略覆盖、设备占用状态 |
| **审计日志** | `/admin/audit` | 操作审计检索：按管理员/目标用户/动作类型筛选 |
| **系统设置** | `/admin/settings` | 全局默认画质参数、商业授权（License）管理 |
| **分享管理** | `/admin/shares` | 全量分享链接/卡密的查看、续期与撤销 |

普通用户经路由守卫被物理隔离在上述页面之外。

## 📋 操作审计 (audit.log)

所有管理端敏感操作自动写入 `data/audit.log`（JSON Lines，逐行一条）：

- **捕获范围**：用户增删改、重置密码、租约发放/续期/撤销、策略变更、分享创建/撤销、强退踢人、批量任务下发等；
- **字段**：时间、操作管理员、目标用户、动作类型、参数详情、客户端真实 IP；
- **可视化**：审计页面支持按用户名模糊搜索与动作类型筛选；历史动作标签（如早期 `assign_devices` 分配设备）保留可读映射。

## 🛡️ 安全基线

- **密码存储**：一律 bcrypt 哈希；历史 sha256+salt 账号在登录成功时透明迁移为 bcrypt；
- **会话令牌**：登录 Token 持久化于 `data/tokens.json`（防抖落盘），服务重启后会话不失效；
- **设备注册密钥**：`/register_device`、`/register_agent` 信令握手支持预共享密钥（`-device-secret` / `CLOUDPHONE_DEVICE_SECRET`），防止未授权设备接入；
- **签名下载 URL**：`/downloads/` 静态目录不直接暴露，文件下载需经 `/api/files/url` 签发带 HMAC 签名的临时链接（10 分钟有效）；
- **服务端密钥**：`data/secret.key`（0600，自动生成）用于下载签名与用户 AI Key 加密存储；
- **最小化数据下发**：普通用户的 `/api/license_status`、tags 等接口仅返回与其设备相关的最小数据集。
