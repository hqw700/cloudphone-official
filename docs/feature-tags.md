# 设备标签管理与大盘过滤 (Device Tags & Grouping)

在管理数十台乃至数百台云手机时，ScrcpyOverWebRTC 提供了强大的 **设备彩色标签体系与大盘响应式分组过滤系统**，帮助您按业务类型、机器机型、归属部门或运行状态对设备进行精细化分类管理。

---

## 🏷️ 核心机制

1. **自定义色彩与名称**：
   - 标签包含唯一 ID、自定义名称（如 `生产环境`、`测试机`、`游戏挂机A组`）以及预设/自定义的高辨识度背景色彩。
2. **云端与本地双轨同步**：
   - 标签变动后，不仅实时保存在浏览器本地 `localStorage`，还会自动同步至信令服务器的 `data/tags.json` 中；
   - 在不同电脑或浏览器登录管理员账号时，标签体系会自动拉取同步，无需重复配置。
3. **大盘毫秒级响应式过滤**：
   - 顶部工具栏汇聚了当前所有的标签 Chips；
   - 点击特定标签即可实现大盘卡片的响应式即时过滤，只展示匹配的设备，大幅降低多机房群控时的查找成本。

---

## 🛠️ 操作指南

### 1. 为设备绑定或创建标签
1. 在大盘页面或设备列表中的设备卡片上，点击 **“编辑标签”** 图标（🏷️）。
2. 在标签弹窗中：
   - **已有标签**：直接点击勾选或取消勾选；
   - **新建标签**：输入新标签名称，选择一种代表颜色，点击“添加标签”。
3. 点击“保存”后，设备卡片上方将即时渲染对应的彩色标签胶囊。

### 2. 在大盘中进行分组筛选
1. 进入 **“监控大盘 (Dashboard)”**。
2. 页面顶部会展示所有已创建的标签过滤器（如 `🏷️ 生产组 (8)`、`🏷️ 测试机 (3)`）。
3. 点击某个标签后，大盘将自动只显示关联了该标签的设备，未匹配的卡片将自动隐藏。
4. 再次点击即可取消过滤恢复全量展示。
