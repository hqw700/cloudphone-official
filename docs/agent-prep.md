# 设备接入准备与开发者选项 (Device Preparation)

在尝试将 Android 物理手机或虚拟机接入 ScrcpyOverWebRTC 管理平台之前，请确保按照本指南完成目标设备的前置系统配置。

---

## 📋 物理真机通用准备清单

### 1. 开启开发者选项
1. 打开手机 **「设置」** ➔ **「关于手机」**（部分品牌在「我的设备」或「系统信息」中）。
2. 连续快速点击 **「版本号 (Build Number)」** 5~7 次。
3. 直到屏幕弹出提示：*“您现在处于开发者模式！”* 或 *“您已开启开发者选项”*。

### 2. 开启 USB 调试
1. 返回设置主菜单，进入 **「系统与更新」**（或「更多设置」/「开发者选项」）。
2. 找到并打开 **「USB 调试 (USB Debugging)」** 开关。
3. 弹出风险提示框时，勾选“我已知晓”并点击 **确定**。

### 3. 开启触控与安全注入权限 (国产品牌必做)
对于小米（MIUI / HyperOS）、OPPO、vivo、魅族等特定国产品牌手机，如果未开启安全权限，控制台**将只能看到视频画面，而鼠标点击完全无法操作**。

| 手机品牌 / 系统 | 必须开启的关键开关 | 注意事项 |
| :--- | :--- | :--- |
| **小米 (MIUI / HyperOS)** | **「USB 调试（安全设置）」** | 开启时系统通常要求手机已插入 SIM 卡并登录小米账号；开启过程中需确认 3 次风险警告 |
| **OPPO / 一加 (ColorOS)** | **「禁止权限监控」** | 开启后可防止系统频繁弹出安全警告弹窗中断操作 |
| **vivo (OriginOS)** | **「USB 安全权限」** | 需在开发者选项中开启允许通过 USB 模拟输入 |
| **魅族 (Flyme)** | **「允许模拟点击」** | 允许外部 ADB 输入事件注入屏幕 |

### 4. 物理数据线与驱动检查
- **数据线要求**：请使用支持高速数据传输的物理 USB 数据线，避免使用仅能充电的廉价电源线。
- **电脑连接模式**：手机连接电脑后，在下拉通知栏中选择 **“仅充电”** 或 **“传输文件 (MTP)”**。
- **授权弹窗**：电脑首次连接手机时，手机屏幕会弹出 **“允许 USB 调试吗？”** 弹窗，请勾选 **「一律允许使用这台计算机进行调试」** 并点击 **确定**。

## 🔍 验证基础连通性

如果您电脑上已安装 ADB 命令行工具，可以在终端中运行以下命令检查设备是否被正确识别：

```bash
adb devices
```

- **正常状态**：输出设备序列号且状态为 `device`：
  ```text
  List of devices attached
  08151FDD40003P    device
  ```
- **未授权状态**（显示 `unauthorized`）：说明手机屏幕上有未确认的调试授权弹窗，请点亮屏幕并点击“允许”。
- **无设备输出**：请检查数据线连接、更换电脑 USB 接口或重新插拔。

## ➡️ 选择您的接入方式

完成上述前置配置后，请根据您的设备类型选择最适合的接入方式：

1. **[方式一：网页端 WebUSB 一键部署](/agent-webusb)**：纯浏览器免驱动插线一键安装（小白首选）。
2. **[方式二：电脑脚本一键包接入](/agent-script)**：通过 PC 终端脚本一键推送（支持 USB / 有线 / 无线 ADB）。
3. **[方式三：Magisk / Root 模块开机自启](/agent-magisk)**：Root 真机开机自启系统守护，无人值守运维。
4. **[方式四：Android App 原生客户端](/app-guide)**：手机安装 App，免电脑被控（支持 Root 与 Shizuku 免 Root）。
5. **[方式五：Docker / Redroid 容器云手机](/agent-docker)**：服务器端 redroid 虚机端口映射与批量纳管。
