# 监控大盘、预览直控与批量群控 (Dashboard & Group Control)

ScrcpyOverWebRTC 的监控大盘（Dashboard）专为大规模云手机同屏监控、极低开销巡检与高效群控而设计。支持 **高频 H.264 预览流、WebCodecs GPU 硬件加速解码、视口感知按需激活、独立预览直控以及多设备批量群控**。

---

## ⚡ 核心设计与技术原理

### 1. H.264 裸流直分发 + WebCodecs GPU 硬解
- **告别 CPU JPEG 压缩**：传统多开大盘在 Android 端通过 CPU 逐帧压缩 JPEG 导致 CPU 飙升发热；本系统直接复用 `scrcpy-server` 输出的低分辨率 H.264 裸流，通过独立的 WebSocket 隧道分发。
- **GPU 硬件加速解码**：浏览器前端利用现代 **WebCodecs API (`VideoDecoder`)** 直接调用本地显卡 GPU 进行硬件解码，直接绘制于 `<canvas>` 画布上，内存占用降低 80% 以上。

### 2. 视口感知按需降级 (IntersectionObserver)
- 大盘滚动时，利用 `IntersectionObserver` 实时监听卡片在屏幕中的可视状态：
  - **可视区域内的卡片**：自动向 Agent 发送 `start_preview` 信令激活 5~10 FPS 的流畅高频预览；
  - **滚出屏幕外的卡片**：自动发送 `stop_preview` 暂停预览流并降级为低频静态快照（维持 0 带宽与 0 编码开销）。

### 3. 独立预览直控 (Preview Direct Control)
- 无需建立耗费握手时间的 WebRTC P2P 连接，直接在大盘卡片底部开启 **“预览直控”** 开关。
- 鼠标在 Canvas 画布上的点击、滑动与拖拽事件，会通过 WebSocket 瞬间下发给 Android 底层。
- **坐标自适应映射**：完美剥离 `object-fit: contain` 产生的边缘黑边，且已彻底适配平板、车载大屏等原生物理横屏机器，触控 100% 精准无偏移。

## 🎮 详细操作指南

### 1. 浏览与平滑缩放
- 进入 **“监控大盘 (Dashboard)”** 页面，即可实时看到所有在线设备的同屏画面。
- 点击顶部工具栏的 **卡片尺寸滑块**，可动态调整每行展示的设备数量（从 1 列到 6 列矩阵自适应排列）。

### 2. 开启预览直控
1. 在目标设备卡片底部，找到并开启 **“预览直控”** 开关。
2. 此时卡片上的 Canvas 将高亮响应鼠标事件：
   - **左键点击 / 拖拽**：模拟手指触摸与滑动手势；
   - **右键点击**：发送 Android 返回键（BACK）；
   - **中键点击 / 点击底部按钮**：发送 HOME 键。

### 3. 批量群控操作 (Group Control)
1. 在大盘顶部工具栏开启 **“群控模式”**。
2. 选择一台设备作为 **主控机**（或勾选多台目标从机）。
3. 当您在主控机画面上进行滑动、点击、输入文字或下发按键时，所有被勾选的从机将毫秒级同步执行完全相同的动作。

## ⚙️ 预览参数调优

在控制台右上角进入 **「设置」➔「缩略预览」**：
- **预览固定码率 (Preview Bitrate)**：可限制大盘预览流的带宽占用（建议设为 `500kbps ~ 1Mbps`）；
- **预览最大分辨率**：可限制预览画面的长边像素（如 `480px` 或 `720px`），大幅降低多开时的网络压力；
- **解码器偏好**：
  - `WebCodecs 硬件解码`（推荐）：利用 GPU 解码，最省 CPU 算力；
  - `WASM 软件解码`：兼容性最强，无浏览器硬解实例数量上限。
