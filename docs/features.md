## 🔍 各模块详细说明

### 1. 流媒体与双轨连接架构
* **WebRTC P2P 直连与智能降级**：基于 Pion WebRTC（Go），优先使用 UDP 直连；在双栈或纯 IPv6 网络下自动建立公网 IPv6 直连，实现零中转带宽成本；在对称 NAT 复杂网络下自动通过内置 `coturn` 进行 TURN 中继。
* **WebSocket 投屏直控 (100% TCP 穿透)**：在企业严格防火墙、校园网或运营商封锁 UDP 的网络环境下，支持一键切换至 WebSocket 高清投屏（1080P/30fps/4Mbps），直接复用 HTTP/HTTPS 端口经信令反代转发，彻底根治“连不上”的问题。
* **全档位 H.264 Profile 兼容梯队**：建立覆盖 Constrained Baseline (PT 102)、Baseline (PT 104)、真机原生 SPS (PT 106)、Main (PT 108) 与 High Profile (PT 110) 的兼容阶梯，彻底根除 iOS Safari / WebKit 拒收视频媒体行（`m=video 0`）导致的黑屏。
* **低延迟流控与微秒级时钟对齐**：深度定制流媒体时钟对齐机制，彻底治理由于静止画面导致的接收端缓冲延迟与首次点击卡顿。
* **音频内录**：通过 UDS 获取系统内录的 Opus 裸流，动态转为 WebRTC AudioTrack 输出，并在前端通过音频直通旁路实现高保真播放。

### 2. 监控大盘与大规模并发群控
* **H.264 预览流与 WebCodecs 硬解**：直接将底层轻量 H.264 裸流通过独立 WebSocket 管道分发，浏览器利用现代 WebCodecs API 调用 GPU 硬件加速解码并渲染至 `<canvas>`，百机同屏依然保持极低 CPU 与内存占用。
* **Pub/Sub 定向分发中枢**：彻底废除全网无差别广播，构建线程安全的发布-订阅映射中心，视频帧仅单播给具备资产权限且主动发起的客户端，多租户数据 100% 零泄漏。
* **四挡推流范围自适应**：支持「屏幕可视（`visible`，滚入拉流滚出休眠）」、「全部在线（`all`）」、「仅勾选设备（`selected`）」与「标签匹配（`tag`）」，大规模监控下节约 80%~95% 下行带宽。
* **大盘直接触控与精准坐标映射**：无需建立完整 WebRTC 连接即可在大盘直接触控，自适应剥离黑边（Letterbox/Pillarbox），完美适配平板、车机等原生物理横屏设备。
* **大规模群控并发引擎**：基于并发协程池派发群控事件，实测 200+ 台机器并发派发延迟仅 ~2.1ms，并发吞吐达 6000 次/秒。

### 3. 物理真机摄像头安防监控模式 (Surveillance Mode)
* **硬件直通监控推流**：基于 Android 底层特权机制，无需点亮手机屏幕（`CP_POWER_ON=false`）、无需打开相机 App、零 CPU 内存拷贝，将闲置手机转变为超低延迟专业安防摄像头。
* **逻辑多摄硬件变焦**：自动识别后置主摄 (1.0x)、超广角镜头 (0.5x/0.6x)、光学长焦镜头 (3.2x/5.0x) 与前置自拍镜头，调用底层硬件驱动实现真实光学视场角换挡。
* **专业安防 OSD 水印与控制侧栏**：常驻呈现设备标识、生效镜头、当前分辨率、实时码率/FPS、电池电量与高温预警（>45°C）、走时时钟及录像指示器；提供 4K/1080P/720P/480P 一键换挡、1.0x~10.0x 无级 PTZ 数字变焦与拖拽漫游。
* **低功耗节能模式 (Camera Eco Mode)**：针对长期监控发热痛点，支持主动关停 OIS/EIS 悬浮线圈防抖马达、关闭自动对焦并将对焦距离锁定在超焦距无穷远使音圈马达断电、关闭重型计算降噪（TNR/GDC）并智能协商 15 FPS 曝光区间，大幅降低机身发热与能耗。
* **安防取证与环境音监听**：支持手机麦克风环境音 Opus 高保真监听，支持 📸 一键原始无损截帧 (JPG) 与 🔴 本地实时封装导出视频录像 (WebM/MP4)。

### 4. 多机直连工作台与多布局形态 (Multi-Device Workspace)
* **多机并发直连控制**：支持同时打开 1~N 台设备进行独立或联动控制，多机直连会话完全隔离。
* **4 大互通工作台布局**：
  1. **弹性网格平铺 (Grid)**：自适应 1x2 双列、2x2 四宫格、2x3/3x3 矩阵，支持双击一键独占放大；
  2. **多标签页保活 (Tabs)**：Chrome 风格多 Tab 切换，后台通道持续保活，秒切零等待，支持左右/上下拆分分屏；
  3. **自由多浮窗 (Floating)**：独立悬浮窗口，支持自由拖拽、八向缩放、视口安全边界保护、置顶与一键平铺；
  4. **移动端单机模式**：手机浏览器自动启用沉浸式单机模式，隐藏多机冗余顶栏，充满全屏，点击列表平滑切机。
* **输入隔离与独占音频焦点**：点击画面激活霓虹蓝光边框，键盘、IME 汉字输入与剪切板严格路由至焦点设备；音频默认仅焦点设备发声，切机平滑过渡，杜绝多机杂音啸叫。

### 5. 批量文本下发与快速短语库
* **多目标并发广播**：在控制台顶部导航栏或群控工具栏中唤起「文本下发」，支持单机、按标签分组勾选或全选在线设备并发下发。
* **100% 汉字落屏注入**：前端经信令广播文本事件，Agent 端自动将非 ASCII 字符路由至底层剪贴板原子通道，支持多行大段文本即时落屏，并可选自动追加回车（Enter 66）。
* **单机直控快捷文本菜单**：PC 控制侧栏与移动端 FAB 菜单常驻提供「⚡ 快捷文本」按键，点击呼出半透明暗黑毛玻璃气泡菜单，预设常用短语即点即入并伴随轻量 Toast 提示。
* **双轨持久化架构**：统一短语数据模型，服务端通过 `/api/quick_texts` 接口在后端以 `quick_texts.json` 文件按用户隔离落盘，前端以本地 `localStorage` 极速响应并静默双向同步，换机不丢数据。

### 6. 运维终端、命令分发与批量安装
* **执行命令 (批量 Shell 分发)**：支持单机或海量多机并发分发 Shell 命令，实时统计执行状态（⏳执行中、✅成功、❌失败）并展示完整输出；针对 `reboot`、`rm -rf` 等高危指令设置强阻断二次确认。
* **ADB 交互式终端 (xterm.js PTY 反代)**：在浏览器内模拟真实交互式终端，支持标准 ANSI 控制字符，流畅运行 `top`、`vi`、`logcat` 等交互程序；优化行高计算与贴底滚动，彻底根除最后一行敲命令被遮挡问题。
* **海量设备选择抽屉 (Target Picker Drawer)**：常驻紧凑摘要胶囊（~38px），点击展开高密搜索抽屉，支持毫秒级模糊搜索、全选匹配项与标签分组，轻松应对 100~500+ 台大规模集群。
* **HTTP Range 断点续传与静默分发**：批量安装支持 RFC 7233 Range 协议分块流式拉取、`If-Range` 脏包防护与网络抖动原地自动重试，消除大文件超时掐断缺陷，支持数百 MB/GB 级应用稳定批量静默安装。

### 7. 高级输入与按键映射系统
* **拼音输入法汉字 100% 落屏 (IME Input)**：1px 全透明 textarea 强锁定焦点与 Composition 合成监听，汉字自动走剪贴板通道绕过 scrcpy 的 ASCII 字符限制，实现电脑拼音输入法流畅打字落屏。
* **静默双向剪切板同步**：焦点回弹自动静默双向同步，支持 `Ctrl+V` / `Cmd+V` 快速粘贴，内置文本去重判重逻辑杜绝无限回环复制。
* **可视化按键映射编辑器**：支持自定义配置 Tap（点击）、Joystick（8 轴移动轮盘）、Swipe（线性滑动）以及 Command（系统物理按键），配置持久化保存在本地。

### 8. 多租户、设备租约与安全审计日志
* **角色与租户隔离**：划分超级管理员与普通用户角色；普通用户通过时长租约（Lease）获得授权，未分配设备物理不可见。
* **一站式全景抽屉**：统一管理用户密码、分配设备矩阵、租期有效时间（支持精确至分钟/小时/天/永久）以及画质/音频策略锁定。
* **全流程操作审计日志**：自动记录所有管理员对用户分配、权限变更、设备控制的敏感操作，落盘至 `admin_logs.json`（原子写入、最多保留 3000 条），支持按用户名与操作类型快速检索。

### 9. 机器临时分享与卡密免登体系
* **临时凭据生成**：支持生成临时分享链接或 8 位卡密（`CP-XXXX-XXXX`），支持 30 分钟至永久有效等多档时长。
* **权限与密码保护**：支持“全功能控制”与“仅观看（只读）”模式，可设置可选的 PIN 访问密码，到期后自动踢断并回收。
* **独立访客播放器**：访客无需登录即可通过专属链接或输入卡密进入直控播放器，配置独立缓存，不污染管理员设置。

### 10. AI 智能排障与设备诊断助手
* **多模型兼容**：支持配置 OpenAI、Claude 以及国内兼容 OpenAI 接口规范的任意 LLM 模型（如 DeepSeek）。
* **自动化诊断工具集**：内置原生 Tool Calling（执行 Shell 指令、读取设备软硬件信息、采集 WebRTC 帧率/丢包/延迟/Jitter 数据、模拟触控按键），全流程可视化展示思考过程与工具调用轨迹。

### 11. 虚拟硬件 HAL 模拟层 (Virtual HAL Injection)
* **Camera HAL (TCP 9001)**：前端采集摄像头或本地视频，以 JPEG/YUV 裸流注入 Android Camera HAL，用于扫码与人脸模拟。
* **GPS HAL (TCP 9002)**：将经纬度坐标注入 GPS HAL，底层以 1s 周期刷新并上报 LocationManagerService。
* **Sensors HAL (TCP 9003)**：将重力、加速度、陀螺仪、折叠角等传感器数据实时注入 Sensors HAL。

### 12. 多终端形态与全场景部署生态
* **WebUSB 免驱一键部署**：纯浏览器插线免驱动直连部署，自动识别 CPU 架构，一键推送并激活 Agent。
* **电脑 ADB 单机与批量并发部署**：`agent-deploy.zip` 部署包内置单机 `run.sh` / `run.bat` 与多机并发 `batch_start.sh` / `batch_start.bat`，自动遍历所有连接设备并发拉起。
* **Magisk 模块离线配置定制工具**：提供免命令行离线配置工具包（`magisk-config-tools.zip`），支持在 Windows 下直接拖拽刷机包至图标完成信令与 ICE 参数预设，刷入手机开机即连。
* **免 Root (Shizuku) 独立 Android 宿主 App**：纯 Kotlin 现代化宿主工程，未 Root 手机通过 Wi-Fi 配对 Shizuku (UID 2000) 即可脱离电脑独立运行 Agent，配备 Android 14+ 前台保活与自愈看门狗。
* **Docker / Redroid 容器云手机**：1 秒免编译打 AIO 镜像，支持 Binder 节点挂载、Loop 设备预分配与 GPU 显存直通硬件加速。

### 13. 全平台兼容与深度国际化
* **移动端全场景体验重塑**：浮动操作球与全屏按钮接入 2.5 秒无触控自动淡隐系统；iOS Safari 检测到全屏请求时弹出 PWA「添加到主屏幕」免地址栏全屏指引。
* **Web-App 100% 国际化与双语守卫**：全站 48 个组件中文硬编码清零，中英文双语字典 1682 键严格对称，集成 `check:i18n` 自动化构建阻断守卫。
