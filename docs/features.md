# 核心功能全景特性 (Feature Matrix)

本文档汇总了 ScrcpyOverWebRTC（穿云投屏）管理系统当前的全部核心功能模块。各项功能均经过生产环境与多形态设备验证，开箱即用。

---

## 🔍 各模块详细说明

### 1. 流媒体与低延迟出流
- **传输架构**：基于 Pion WebRTC（Go），优先使用 UDP 直连；在双栈或纯 IPv6 网络下自动建立公网 IPv6 直连，实现零中转带宽成本；在对称 NAT 复杂网络下自动通过内置 `coturn` 进行 TURN 中继。
- **真机硬件兼容**：物理真机默认强制 `profile=1`（Baseline Profile），强迫手机硬件编码器输出兼容流，杜绝 WASM/WebCodecs 解码黑屏。
- **时间戳与防抖**：HW-PTS 硬件时间戳直通，配合 10 FPS 自动复制帧保活机制，彻底治理由于静止画面导致的 Jitter Buffer 膨胀与首次点击卡顿。
- **音频内录**：通过 UDS 获取系统内录的 Opus 裸流，动态转为 WebRTC AudioTrack 输出。

### 2. 高频大盘预览与直控群控
- **H.264 预览与 WebCodecs 硬解**：直接将底层低分辨率 H.264 裸流通过独立 WebSocket 分发给前端，利用浏览器 WebCodecs GPU 硬解渲染至 Canvas。
- **视口感知降级**：仅对屏幕可见区域内的卡片拉取高频流（5~10 FPS），滚出可视区自动暂停并降级为低频快照，实现百台同屏极低负载。
- **预览直控与坐标映射**：无需建立昂贵的 WebRTC 连接即可在大盘直接触控，自适应剥离边缘黑边，且已彻底适配平板、车机等原生横屏机器。

### 3. 多账号与多租户权限管理
- **角色体系**：超级管理员（`admin`）与普通用户（`user`），支持专属 VIP 免计费特权。
- **设备权限隔离**：管理员可将指定设备分配给指定用户，未分配设备对普通用户物理不可见。
- **一站式全景抽屉**：统一管理用户密码、云币资产、分配设备列表、有效期（+7天/+30天/+1年/永久）以及画质/音频强制锁定策略。
- **操作审计日志**：自动记录所有管理员对用户、设备、资产的操作记录，存储于 `admin_logs.json`（原子写入、最多保留 3000 条），支持按用户名与操作类型快速检索。

### 4. 机器分享与卡密免登录体系
- **临时凭据生成**：支持生成临时分享链接或 8 位卡密（`CP-XXXX-XXXX`），支持 30 分钟至永久有效等多档时长。
- **权限与密码保护**：支持“全功能控制”与“仅观看（只读）”模式，可设置可选的 PIN 访问密码，到期后自动踢断并回收。
- **独立访客播放器**：访客无需登录即可通过专属链接或输入卡密进入直控播放器，配置独立缓存，不污染管理员设置。

### 5. 高级输入系统
- **100% 汉字落屏**：通过 1px 透明 textarea 会话管理与 Composition 合成监听，在检测到中文时自动走静默双向剪贴板注入，绕过 scrcpy 的 ASCII 字符限制。
- **静默双向剪切板**：焦点回弹自动同步，支持 `Ctrl+V` / `Cmd+V` 快速粘贴，内置判重逻辑防止回环拷贝。
- **可视化改键编辑器**：支持 Tap（点击）、Joystick（8 轴移动轮盘）、Swipe（线性滑动）以及 Command（系统物理按键），配置保存在本地 `localStorage`。

### 6. 远程调试与文件管理
- **P2P WebADB 隧道**：在 WebRTC DataChannel 上实现纯 JavaScript 握手的 WebADB，免装客户端即可进行 ADB 调试。
- **P2P 文件管理器**：基于 DataChannel 的二进制分块传输，支持流量控制（BWE），提供远程文件浏览、新建、重命名、删除与极速双向传输。
- **批量命令与 APK 分发**：支持向多台设备并发分发 Shell 命令，支持将 APK 上传至信令服务器后异步广播给各 Agent 执行静默安装。

### 7. AI 智能排障助手
- **多模型兼容**：支持配置 OpenAI、Claude 以及兼容 OpenAI 接口规范的模型（如 DeepSeek）。
- **自动化诊断**：内置 Tool Calling 工具集（执行 Shell 命令、读取设备信息、采集 WebRTC 丢包/延迟/Jitter 数据、模拟触控按键），全流程展示思考过程与工具调用轨迹。

### 8. 虚拟 HAL 底层硬件数据注入
- **Camera HAL (TCP 9001)**：前端采集摄像头或本地视频，以 JPEG/YUV 裸流注入 Android Camera HAL。
- **GPS HAL (TCP 9002)**：将经纬度坐标注入 GPS HAL，底层以 1s 周期刷新并上报 LocationManagerService。
- **Sensors HAL (TCP 9003)**：将重力、加速度、陀螺仪、折叠角等传感器数据实时注入 Sensors HAL。

### 9. 多形态部署与批量初始化
- **WebUSB 免驱一键部署**：浏览器原生通过 WebUSB 与手机通信，自动侦测 CPU 架构（`arm64` / `armeabi-v7a` / `amd64`）并推送 Agent，无需在电脑上预装 ADB。
- **ADB 单机与批量并发部署**：`agent-deploy.zip` 部署包内置单机 `run.sh` / `run.bat` 与多机并发 `batch_start.sh` / `batch_start.bat`，自动遍历所有正常连接设备并一键并行拉起守护进程。
- **Magisk 模块与离线定制工具**：提供开机自启 Magisk / KernelSU / APatch 模块包及轻量离线配置工具包（`magisk-config-tools.zip`），支持在 Windows 下直接拖拽 ZIP 刷机包至 `configure_magisk.bat` 图标完成免命令行参数预设，手机刷入后开机即连。
- **自适应部署大屏**：控制台部署中心采用三步走自适应步骤流排版，代码块防遮挡安全边距，全端设备极致贴合。
