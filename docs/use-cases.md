# 应用场景与硬件要求

> [!IMPORTANT]
> **概念澄清：本系统是用于「搭建云手机管理平台」，而不是「创建云手机虚拟系统」本身。**
> 
> 本系统（穿云投屏）扮演的是**信令中心、控制中心、画面分发端与设备管理大盘**。它可以将你已有的各种安卓物理真机、模拟器、或是已经起好的 redroid 容器统一收拢，并以极速低延迟的形式通过浏览器对外提供控制、群控和运维。

---

## 💻 基础硬件与环境要求

要成功跑通这套方案，你只需要提供以下两部分基础硬件环境：

| 角色 | 硬件 / 环境要求 | 说明 |
| :--- | :--- | :--- |
| **1. 控制管理服务端** | NAS (飞牛/群晖) Docker / 普通 PC（Win/Mac/Linux）/ 云服务器 (2C/2G/3Mbps 即可) | 负责运行 `webrtc-signaling` 信令服务端和托管 Web 控制网页。 |
| **2. 待接入安卓设备端** | 具有 **ADB 调试** 或 **Root 权限** 的 Android 物理手机 / 电脑安卓模拟器 / `redroid` 虚拟机容器 | 负责运行 `cloudphone-agent` 代理，只需要以shell或root权限在后台运行，不需要连接有线或无线ADB |

---

## 🚀 核心应用场景

穿云投屏目前支持局域网、云服务器公网以及特定的设备直连，覆盖了从个人娱乐、极客折腾到商业群控的多种业务场景。

### 1. 局域网NAS / 物理 PC 部署场景
此方案最适合拥有 NAS（如飞牛私有云）或者本地常开 PC 的个人极客及工作室用户。

*   **1.1 闲置设备的多端轻量互连**  
    将家里的闲置手机挂载在内网，在电脑、平板（iPad/安卓）或者苹果手机（iOS）的浏览器里直接打开官网后台即可对该手机进行连接和完整控屏。  
*   **1.2 大规模设备群控与批量管理**  
    支持高频预览大盘、设备分组管理、指令批量下发，以及 APK 应用程序的批量分发静默安装。
*   **1.3 高性能无线投屏与办公协作**  
    支持静默双向剪切板同步（焦点回弹自动同步）、网页端 IME 汉字输入法无阻碍注入、P2P 文件管理器直接上传/下载文件，充当极其丝滑的免装客户端无线投屏器。  
*   **1.4 电脑玩安卓手游 (云手游挂机)**  
    系统提供自研的可视化改键编辑器，支持 Tap、Swipe、Joystick 等按键映射。支持原画质输出、高帧率（最高支持 120fps）、超低延迟（端到端延迟 <50ms），在网页里即可畅玩手游。
*   **1.5 开发者与运维高级调试**  
    可以直接在网页里唤起基于 `xterm.js` 的反代终端命令行(shell权限或root权限)，集成AI工具和性能监控大盘。
*   **1.6 闲置手机改造为高清监控摄像头**  
    将闲置的废旧手机配置好摄像头注入，如果宽带具备公网 IPv6 地址，可以从外面直接打开网页查看家里的实时摄像监控，变废为宝。
*   **1.7 内网穿透与 WebRTC 穿透探索**  
    本系统建立在 WebRTC 架构之上，使用UDP传输。如果要玩内网穿透，并不是很容易。大家各显神通

---

### 2. 云服务器 (VPS) 公网部署场景
此方案最适合拥有公网云服务器（最便宜的 2核/2G内存/3Mbps 带宽的入门级服务器即可）的商用或异地协同团队。

*   **2.1 跨公网远程控制与运维**  
    将部署服务端跑在云端，可以在任意地方跨越公网，直接操作和调试放在家里的物理手机。即使部署在公网，局域网访问还是会走本地直连。
*   **2.2 第三方云手机集中管理**  
    支持将购买的红手指、雷电云、多多云等第三方云手机，收拢到你自己的管理大盘下进行统一管理和分配。
*   **2.3 商业化多租户设备出租**  
    服务端内置了多账号和简单的租户划分逻辑。你可以把自己的大量手机挂在云服务器下进行分组，分配不同的账号给不同的客户去异地控屏使用。

---

### 3. 手机对手机直连场景
*   **3.1 手机对手机直连控制**
    > [!WARNING]
    > **不推荐：** 虽然可以通过将服务端与 Agent 直接交叉运行在 Android 手机上，实现手机控制手机。但由于手机端系统网络限制、功耗和后台进程限制，连接稳定性较差，仅建议作为概念验证（PoC）或应急折腾使用。
