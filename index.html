Full Feature Matrix

全景功能大盘与核心技术矩阵

全面覆盖 WebRTC 流媒体、高频群控大盘、Android App 双引擎、虚拟 HAL 注入与 AI 智能排障。

📡

高频大盘实时预览

独立 WebSocket 二进制 H.264 裸流分发，抛弃传统 CPU 压缩 JPEG 方案，支持数十台设备大盘高帧率并发流畅监控。

🎮

独立预览直控 (Direct Control)

无需建立昂贵的 WebRTC P2P 握手，即可在大盘 Canvas 卡片上直接滑动点击操作云手机，极致响应，瞬间直控。

🎯

批量触控与按键群控

支持批量勾选目标云手机，一键将屏幕触控手势、按键宏同步广播至全量设备，大幅提升群控运维效率。

📦

应用批量分发与静默安装 (v0.3.0)

上传 APK 一键广播分发至多台云手机，Agent 后台异步并发 `pm install -r` 静默安装，在管理大盘实时汇总反馈安装状态。

📂

P2P 直连文件管理器 (Web & App)

依托 DataChannel P2P 物理通道与滑动窗口 BWE 流控，支持对远端云手机目录进行全功能浏览、新建、删除及极速双向传输。

📢

批量命令行分发终端

结合设备标签一键全选，并发广播下发 ADB Shell 指令，在大盘实时展示各机器执行状态与 stdout/stderr 输出。

🔄

坐标自适应与 90° 旋转逆映射

自动解析视频帧物理像素，剥离 `object-fit: contain` 黑边；支持原生横屏设备（车机/Pad）90° 顺时针逆映射，触控 100% 精准。

👁️

视口感知智能降级与 GPU 硬解

感知大盘滚动视口 (IntersectionObserver)，仅对可见区域卡片推流，结合 WebCodecs GPU 硬件解码，极致节省带宽与 CPU。

📱

APP 主控端直控大盘

支持原生 Android App 登录连接大盘直控云手机，提供多点触控、悬浮金刚键、端到端延迟悬浮球及软键盘抑制。

⚡

Root / Shizuku 双引擎被控

物理手机免连接电脑，支持 Root 或无线调试 Shizuku (ADB) 双引擎授权，一键免电脑拉起 Agent 受控运行。

🏠

独立单机模式 (手机内置 Server)

信令与 Web 托管可直接解压运行在手机内部，通过局域网/公网 HTTPS 直连访问，彻底摆脱外部服务器依赖。

🧩

Magisk / KSU 系统服务保活

支持作为 Magisk / KernelSU / APatch 插件模块作为底层服务开机自启保活，防 LMK 误杀，稳定性达 99.9%。

🛠️

cpctl 工具与 MT管理器配置

内置 `cpctl` 终端命令行交互配置工具，亦可直接使用 MT管理器 编辑 `/data/adb/modules/cloudphone-agent/config` 热生效。

📁

App 原生直连文件管理 (v0.3.1)

App 内部集成 P2P 文件管理器，支持对远端云手机目录进行直观浏览、新建、重命名、删除及高速双向上传下载。

⏱️

HW-PTS 硬件级时间戳 Passthrough

捕获 MediaCodec 硬件编码器原始 PTS 时间戳解算 RTP Duration，彻底解决累积漂移，Jitter Buffer 降至 10ms 内。

🔒

三通道 UDS 物理隔离

视频 (@video)、控制 (@control) 和多点触控 (@touch) 三路 Socket 隔离运行，高频触控绝不抢占视频带宽。

🎵

Opus 音频内录直通

Android 后台 `scrcpy-server` 输出 Opus 裸流并转换为 WebRTC AudioTrack，画面与声音精准同步低延迟输出。

🌐

P2P IPv6 直连与 TURN 中继

自动收集 IPv6 候选地址实现公网 0 带宽成本直连；严格对称 NAT 环境自动匹配内置 `coturn` TURN 中继中转。

⚙️

全局 vs 单设备双轨定制隔离

独立保存特定设备的分辨率、码率、帧率、通道策略 (auto/direct/relay) 和 IP 偏好 (v4/v6)，重连瞬间热生效。

🌙

息屏连接防窥与硬件节电

唤醒录屏后自动切断物理真机屏幕背光，具备防窥、防硬件发热、大幅延长电池寿命的作用。

📋

静默双向剪切板 (防回环)

焦点回弹自动无感同步剪贴板，支持快捷键粘贴，两端以最近同步文本判重，彻底避免无限复制回环。

✍️

IME 拼音汉字无错落屏

1px 透明 Textarea 锁定焦点与 Composition 拼音合成管理，非 ASCII (汉字) 自动走剪切板注入，100% 选词落屏。

🕹️

可视化改键与摇杆引擎

内置可视化拖拽编辑器，支持 Tap(单击)、Joystick(跑动摇杆)、Swipe(线性滑动)及系统按键映射绑定。

💻

Interactive Shell (xterm.js)

嵌入 xterm.js ANSI 仿真终端，支持多 Tab 会话，可流畅运行 top、vi、logcat 等真交互式程序。

📢

批量命令分发终端

支持根据设备标签一键点选全选，并发下发 ADB Shell 命令，在大盘分组高亮展示各机器执行状态与 stdout/stderr。

☁️

自定义快捷宏云同步 (v0.3.0)

控制台右侧支持自主增删改快捷宏命令，数据自动在信令 Server 端持久化存储 (`shortcuts.json`) 实现多端漫游。

🤖

AI 智能排障代理

完美接入 OpenAI、Claude 及 DeepSeek，自主运行原生工具链 (Tool Calling)，查命令、抓包并分析卡顿根本原因。

🔍

AI 思考与工具 Trace 日志

顶层集成“思考过程与工具调用日志”面板，实时展现 Prompt 解析、逻辑推理以及下发 Shell / Stats 工具的日志。

🔌

P2P 隧道 WebADB 调试

依托 DataChannel 专用通道，前端纯 JS 实现 WebADB 握手，直接在浏览器上与云手机 adbd 通信，免本地安装 ADB。

📦

P2P 文件管理与静默分发

基于 DataChannel 滑动窗口 BWE 流控传输，支持文件浏览、上传下载及异步并发 `pm install -r` 静默应用安装。

📊

离线设备列表与状态持久化 (v0.3.0)

信令服务器与管理平台全面优化设备注册心跳，引入离线设备持久化视图，方便大盘对离线设备的统一追踪。

🩹

切网恢复与网络链路自愈 (v0.3.0)

彻底修复因 Wi-Fi / 移动网络切换导致的设备离线误报与假死，网络重连后 Agent 自动触发注册上报与链路自愈。

📷

Camera HAL 摄像头裸流注入

捕获网页摄像头流，Agent 解码为 YUV420p 裸流直注 TCP 9001 端口，云手机内相机 App 瞬间捕捉本机画面。

📍

GPS HAL 虚拟定位

Agent 开放 TCP 9002 端口接收经纬度，动态更新 GNSS 配置文件，定位 HAL 线程 1s 轮询上报 LocationManager。

🧭

Sensors HAL 传感器模拟

开放 TCP 9003 端口接收 JSON 数据，动态更新内存 `gMockSensorData`，实时模拟加速度计、陀螺仪与折叠角。

👑

多账号与租户隔离 (Kick 强退)

划分 admin 与普通用户角色，提供细粒度设备分配；管理员可实时监控活动连接并一键强退 (Kick) 释放设备。

🏷️

设备彩色标签与大盘筛选

支持给设备设置自定义彩色标签，本地+云端 HTTP API 双轨同步，大盘与 ECharts 监控走势响应式即时过滤。

📈

WebSocket 指标与 ECharts 趋势

Agent 端 5s 差分采集 CPU、内存、磁盘、网速与温度，前端 Pinia 滑动窗口与 ECharts 展现设备实时性能折线图。

Get Started

三步开启您的云手机之旅

“穿云投屏”原生支持在 MacOS、Linux 和 Windows 上交叉编译并一键运行。跟随以下极简流程，立刻启动您的服务。

阅读完整部署文档
bash - Terminal
# 1. 使用 Docker 一键运行信令服务端 (PUBLIC_IP为宿主机IP或者公网IP)
docker run -d --net=host -e PUBLIC_IP=192.168.1.100 buutuu/scrcpy-over-webrtc:latest
# 2. 免驱一键部署：浏览器访问 https://192.168.1.100:8443 点击「部署新设备」自动配置
# 支持自动判定架构并推送 Agent 服务，Setsid 守护常驻启动
# 3. 命令行手动部署：下载一键资源包推送并启动 Agent
unzip agent-deploy.zip && cd agent-deploy && ./run.sh -id phone-01 -signaling wss://192.168.1.100:8443
